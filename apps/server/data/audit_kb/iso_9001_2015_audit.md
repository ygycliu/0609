# ISO 9001:2015 质量管理体系 - 审核要点

## 标准结构
ISO 9001:2015 采用 PDCA 循环 + 基于风险的思维 + 过程方法
- 10 个条款（4-10）
- 4.1-4.4 组织环境
- 5.1-5.3 领导作用
- 6.1-6.3 策划
- 7.1-7.5 支持
- 8.1-8.7 运行
- 9.1-9.3 绩效评价
- 10.1-10.3 改进

## 关键条款审核要点

### 4. 组织环境
- 4.1 组织及其环境：SWOT/PESTLE 分析是否充分？
- 4.2 相关方需求：相关方清单 + 关注程度 + 应对策略
- 4.3 体系范围：是否明确？删减合理吗？
- 4.4 过程：过程图 + 顺序 + 接口 + 责任 + KPI

### 5. 领导作用
- 5.1 领导作用与承诺：最高管理者亲自参与
- 5.2 方针：与战略一致 + 沟通 + 可获取
- 5.3 岗位责任：全员理解 + 能力匹配

### 6. 策划
- 6.1 风险与机遇：识别 + 应对措施 + 实施证据
- 6.2 目标：SMART + 分解到部门 + 监测
- 6.3 变更：变更策划 + 后果评估 + 完整性

### 7. 支持
- 7.1 资源：人/财/物/技术 + 基础设施 + 知识
- 7.2 能力：培训 + 教育 + 经验 + 岗前培训
- 7.3 意识：员工知道方针 + 贡献 + 不符合后果
- 7.4 沟通：内/外/相关方 + 时机 + 内容
- 7.5 文件化信息：创建/更新/控制（受控 + 版本）

### 8. 运行（最大占比 ~50%）
- 8.1 运行策划与控制
- 8.2 产品和服务要求：标书/合同/订单评审
- 8.3 产品和服务的设计开发（如适用）
  - 8.3.1 策划
  - 8.3.2 设计开发输入
  - 8.3.3 输出
  - 8.3.4 评审
  - 8.3.5 验证
  - 8.3.6 确认
  - 8.3.7 更改控制
- 8.4 外部提供的过程/产品/服务控制
- 8.5 生产与服务提供
  - 8.5.1 生产控制
  - 8.5.2 标识与可追溯
  - 8.5.3 顾客/外部供方财产
  - 8.5.4 防护
  - 8.5.5 交付后活动
  - 8.5.6 更改控制
- 8.6 产品和服务放行
- 8.7 不合格输出控制：标识/隔离/评审/处置

### 9. 绩效评价
- 9.1 监测测量分析评价：什么 + 何时 + 如何 + 谁
- 9.1.1 总则
- 9.1.3 分析与评价
- 9.2 内部审核
  - 计划（覆盖所有过程）
  - 准则 + 范围
  - 审核员选择 + 客观性
  - 检查表
  - 报告
  - 不符合项 + 整改
- 9.3 管理评审
  - 计划（每年 ≥1 次）
  - 输入：审核结果/顾客反馈/过程绩效/不符合/纠正措施/风险/法规变化/改进机会
  - 输出：改进机会 + 变更需求 + 资源需求

### 10. 改进
- 10.1 总则：改进机会识别
- 10.2 不合格与纠正措施：原因分析 + 措施实施 + 有效性验证
- 10.3 持续改进：趋势分析 + 标杆对比 + 创新

## 删减要求
- 仅允许删减第 8 章部分条款（如 8.3 设计开发）
- 必须证明"删减不影响产品符合性"
- 文件化信息说明

## 常见不符合项
1. 目标未分解到部门（6.2）
2. 内审不全（9.2）
3. 管理评审输入材料不足（9.3）
4. 培训记录不全（7.2）
5. 不合格品未隔离（8.7）
6. 文件未受控（7.5）
