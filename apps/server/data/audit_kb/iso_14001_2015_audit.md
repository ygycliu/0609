# ISO 14001:2015 环境管理体系 - 审核要点

## 核心结构（基于 ISO 14001:2015）
- 10 个条款（4-10）
- 重点：环境因素 + 合规义务 + 持续改进

## 关键条款审核要点

### 4. 组织所处的环境
- 4.1 组织环境：地理位置/周边社区/法规环境
- 4.2 相关方：政府/居民/上下游/环保组织
- 4.3 体系范围：明确 + 多场所考虑
- 4.4 体系：过程方法 + PDCA + 生命周期视角

### 5. 领导作用
- 5.1 领导承诺：环境保护 + 污染防治承诺
- 5.2 环境方针：污染防治 + 合规 + 持续改进 + 生命周期间接影响

### 6. 策划
- 6.1.1 总则：风险与机遇（合规义务 + 重要环境因素 + 上下文 + 相关方）
- 6.1.2 环境因素（最核心）：
  - 识别全面（生产 + 服务 + 办公 + 上下游）
  - 考虑生命周期（原料 + 产品 + 处置）
  - 评价准则（法规 + 频次 + 规模 + 严重性）
  - 重要环境因素清单（更新频率 ≥1/年）
- 6.1.3 合规义务：法规识别 + 评价 + 跟踪
- 6.1.4 策划：应对措施 + 应急 + 资源

### 7. 支持
- 7.1 资源
- 7.2 能力：环保培训 + 关键岗位资格
- 7.3 意识：全员环境意识
- 7.4 沟通：内/外/相关方 + 投诉处理
- 7.5 文件化信息

### 8. 运行（重点）
- 8.1 运行策划与控制
- 8.2 应急准备与响应
  - 潜在事故（化学品/火灾/废水超标）
  - 应急预案（每年演练 +演练记录）
  - 应急物资（消防/吸附/中和）
- 8.3 重要环境因素运行控制
  - 操作规程上墙
  - 关键参数监测
- 8.4 合规义务
  - 监测计划（废气/废水/噪声）
  - 在线监测（如有）
  - 年度监测报告
  - 排污许可证（按时续期）
  - 排污申报
  - 排污费缴纳
- 8.5 采购：考虑环境因素
- 8.6 应急
- 8.7 外包：环境影响

### 9. 绩效评价
- 9.1.1 监测：环境绩效指标（KPI）
- 9.1.2 合规义务评价：每条法规 → 实际符合性
- 9.2 内审（覆盖 6.1.2/6.1.3/8.4）
- 9.3 管理评审（输入含环境绩效）

### 10. 改进
- 10.1 持续改进
- 10.2 不符合与纠正措施
- 10.3 持续改进

## 关键环境因素类别
- 大气污染：SO2/NOx/颗粒物/VOCs
- 水污染：COD/BOD/氨氮/重金属
- 土壤污染
- 噪声污染
- 危险废物：HW 编号/联单/资质单位
- 一般工业固废
- 能源消耗：电/煤/油/水
- 原材料消耗
- 生物多样性影响
- 温室气体

## 强制法律法规（中国）
- 《环境保护法》
- 《大气污染防治法》
- 《水污染防治法》
- 《噪声污染防治法》
- 《固体废物污染环境防治法》
- 《环境影响评价法》
- 《清洁生产促进法》
- 《排污许可管理条例》
- 各行业排放标准（GB 系列）

## 常见不符合项
1. 环境因素识别不全（缺原料/产品/处置环节）
2. 重要环境因素无运行控制
3. 排污许可证过期
4. 应急预案超期未演练
5. 危险废物无资质单位处置
6. 监测计划未执行
7. 法规清单未及时更新
