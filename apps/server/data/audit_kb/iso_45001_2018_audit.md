# ISO 45001:2018 职业健康安全管理体系 - 审核要点

## 核心结构
- 10 个条款（4-10）
- 与 ISO 14001:2015 结构高度一致
- 重点：危险源 + 风险 + 机会 + 领导承诺 + 员工参与

## 关键条款审核要点

### 4. 组织环境
- 4.1 组织环境：内部/外部议题（行业风险/法规环境）
- 4.2 相关方：员工/分包方/客户/监管/工会
- 4.3 体系范围：员工/分包方/访客全覆盖
- 4.4 体系：PDCA + 过程方法

### 5. 领导作用与员工参与
- 5.1 领导作用：最高管理者承诺 + 资源
- 5.2 OH&S 方针：预防为主 + 持续改进
- 5.3 组织角色：责任 + 权限
- 5.4 咨询与参与（核心）：
  - 员工参与决策
  - 工会代表
  - 安全员设置
  - 班前会
  - 合理化建议

### 6. 策划
- 6.1.1 总则：风险与机遇
- 6.1.2 危险源辨识与风险评价（最核心）：
  - 全面性：常规 + 非常规 + 紧急 + 变更
  - 三种状态：正常/异常/紧急
  - 三种时态：过去/现在/将来
  - 七种类型：物理/化学/生物/心理/生理/安全/社会
  - 评价方法：LSR/LEC/RBS
  - 不可接受风险清单
- 6.1.3 适用法律法规
- 6.1.4 策划：消除/替代/工程控制/管理控制/PPE
- 6.1.5 目标：量化（零事故 / 零职业病 / 隐患整改率）
- 6.1.6 应急准备与响应

### 7. 支持
- 7.1 资源
- 7.2 能力：特殊工种持证 + 三级安全教育
- 7.3 意识：员工知道风险 + 不安全行为后果
- 7.4 沟通：内部/外部/监管
- 7.5 文件化信息

### 8. 运行
- 8.1 运行策划与控制
- 8.1.1 一般策划
- 8.1.2 消除危险源
- 8.1.3 变更管理：厂房/设备/工艺/法规
- 8.1.4 采购：考虑 OH&S 要求
- 8.1.5 外包：监督分包方 OH&S 表现
- 8.2 应急准备与响应（核心）：
  - 应急救援预案
  - 演练（每年 ≥1 次）
  - 应急物资（消防/急救/防化）
  - 消防演练 + 记录
- 8.3 危险源辨识持续

### 9. 绩效评价
- 9.1.1 监测：主动（隐患排查）+ 被动（事故）
- 9.1.2 评价：合规 + 风险 + KPI
- 9.2 内审（覆盖 6.1.2）
- 9.3 管理评审

### 10. 改进
- 10.1 持续改进
- 10.2 不符合与纠正措施（含事故调查）
- 10.3 持续改进

## 强制性安全要素（中国）
- 三级安全教育（厂级/车间/班组）
- 特种作业证：电工/焊工/登高/叉车/压力容器
- 工伤保险
- 职业健康体检（岗前/在岗/离岗）
- 职业病危害因素检测（每年）
- 劳动防护用品（劳保）发放
- 工伤事故报告（重大事故）
- 安全生产投入（提取）

## 危险源类别
- 物理：噪声/振动/电离辐射/非电离辐射/高处坠落/机械伤害
- 化学：粉尘/毒物/腐蚀/易燃易爆
- 生物：细菌/病毒/传染病媒介
- 心理：超负荷/单调/倒班/性骚扰
- 生理：人机工效/强迫体位
- 安全：设备故障/防护缺陷/信号缺陷
- 社会：暴力/骚扰

## 常见不符合项
1. 危险源辨识不全（缺心理/生理）
2. 特种作业证过期
3. 应急预案超期未演练
4. 劳保用品发放台账不全
5. 工伤事故未调查
6. 职业健康体检超期
7. 三级安全教育缺失
8. 分包方 OH&S 未管理
9. 变更管理缺失
10. 隐患排查走过场
