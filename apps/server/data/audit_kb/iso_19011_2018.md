# ISO 19011:2018 审核管理体系指南

## 适用范围
- 所有类型管理体系审核（质量/环境/职业健康安全/能源/信息等）
- 第一方/第二方/第三方审核

## 审核原则（7 项）
1. 诚信：职业素养 + 真实表达
2. 公允表达：真实准确报告
3. 职业素养：认真负责
4. 保密性：信息安全
5. 独立性：客观公正（无利益冲突）
6. 基于证据的方法：理性方法
7. 风险导向方法：关注风险

## 审核类型
- 内部审核（第一方）
- 供应商审核（第二方）
- 认证审核（第三方）
- 联合审核（多个体系）

## 审核方案管理
- 方案策划（每年）
- 实施
- 监视与评审
- 改进

## 审核启动
1. 指定审核组长
2. 确定审核目标/范围/准则
3. 资源文件可用性
4. 组建审核组

## 审核活动
### 第 1 阶段：文件评审
- 手册/程序/重要记录
- 法规识别
- 主要环境因素/危险源
- 内审 + 管理评审记录

### 第 2 阶段：现场审核
- 首次会议
- 现场收集证据（访谈/观察/文件）
- 形成审核发现
- 末次会议

## 审核证据收集方法
1. 访谈（管理层/员工/分包方）
2. 现场观察（5S/标识/防护/操作）
3. 文件查阅（手册/程序/记录）
4. 数据分析（趋势/统计）

## 不符合项分级
- 严重不符合：
  - 体系系统性失效
  - 重大风险/后果
  - 法律法规严重违规
  - 客户重大投诉
- 一般不符合：
  - 偶发性问题
  - 局部失效
- 观察项：
  - 改进建议
  - 潜在风险

## 审核报告
- 内容：审核目标/范围/准则/发现/结论
- 时限：现场结束后 2-4 周
- 跟踪：不符合项整改 + 验证

## 审核员能力
- 教育背景
- 工作经历
- 审核员培训（40小时+）
- 专业能力（行业知识）
- 个人素质
