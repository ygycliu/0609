# 佳士洁认证申请书（HZCX-01-1-D0）

按佳士洁与华中国际签订的合同
《HZCX-01-3-D2 管理体系、服务认证认证合同书-宁夏佳士洁水处理有限公司-初次认证QES.docx》，
用华中官方模板 HZCX-01-1-D0《管理体系/服务认证申请书》生成申请书。

## 产出

| 文件 | 说明 |
|---|---|
| `宁夏佳士洁水处理有限公司-管理体系、服务认证申请书-HZCX-01-1-D0.docx` | 申请书本体，8 页，合同能确定的字段已填，其余为 `【待补充】` |
| `缺失信息清单.md` | 29 项待甲方补充的信息，按申请书页码归类 |

## 生成方式

```bash
python3 apps/server/src/scripts/fill-hzcx-011-application.py \
    <输出.docx> [--template 模板.docx] [--data 数据.json]
```

模板默认取 `/opt/ai-consulting-center/data/templates/HZCX-01-1-D0.docx`。

脚本与 `fill-hzcx-contract.py` 同一套路：直接编辑 `word/document.xml` 里的文本 run，
保留 run / 段落自带的字体、字号、加粗、下划线等格式，只替换文字内容。

合同里没有的字段统一填 `【待补充】`，脚本运行结束会打印待补充清单。
甲方补充信息后，用 `--data` 传 JSON 覆盖默认值即可重新生成。
