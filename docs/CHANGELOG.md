## 🏷️ 版本规则

- **feat**：新功能
- **fix**：修复 bug
- **refactor**：重构（不增加功能不修 bug）
- **data**：数据变更（迁移/补建/清洗）
- **ui**：UI 调整（不改逻辑）
- **rename**：改名/重组
- **docs**：文档

### 🎯 核心新增：认证证书预警系统

**业务背景**：基于 4 阶段认证周期（初次 / 监督一 / 监督二 / 再认证）建立智能预警

#### ✨ 功能亮点

- **4 阶段自动分类**：基于 issue_date + valid_until 计算当前/下一阶段
- **5 级预警**：已过期 / 再认证紧急 / 再认证预警 / 即将到期 / 正常
- **穿透查询**：所有统计卡片点击即筛选
- **批量确认**：checkbox + 批量按钮
- **智能代办**：紧急模式自动推送 todo 到待办
- **撤销机制**：恢复显示 + 清理 todo

### 🎯 核心新增：审核员档案系统

**业务背景**：管理 45+ 个审核员档案，含证书 OCR 自动识别

#### ✨ 功能亮点

- **审核员列表**：分页 + 搜索 + 状态/级别/机构/专业筛选
- **证书 JSON 存储**：certificates / attachments 用 JSONB
- **OCR 自动识别**：Tesseract + chi_sim + eng
- **证书预览 Modal**：缩放/切换/下载/OCR
- **批量合并**：相同人不同记录合并
- **6 体系识别**：EMS/QMS/OHSMS/ISMS/ITSMS/BCMS
